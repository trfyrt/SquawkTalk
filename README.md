## 🦜 What is SquawkTalk?

SquawkTalk is a fast-paced browser typing game where you train a parrot by typing 
words that match given syllables — all within 60 seconds.

Type **TRACK** when Chirpy squawks **"TR"**. Keep your streak alive. Watch your 
multiplier explode.

## ✨ Features

| Feature | Description |
|---|---|
| 🔤 Syllable Prompts | Type any valid word containing the given syllable (e.g. "TR" → "STRAY", "ULTRA") |
| ⏱️ 60-Second Blitz | Short, addictive sessions — easy to pick up, hard to put down |
| 🔥 Combo Multiplier | Maintain streaks to hype up Chirpy and multiply your score |
| 🏆 Parrot IQ Rank | Earn a rank from "Sleepy Hatchling" to "Polyglot Professor" *(coming soon)* |

---

## 🕹️ How to Play

1. A syllable appears on screen (e.g. **"BR"**)
2. Type any valid English word containing it (e.g. **"BRING"**, **"OMBRE"**)
3. Hit Enter — Chirpy learns the word, your score goes up
4. Keep your streak alive to build combos and multiply points
5. 60 seconds. How many words can you teach?
